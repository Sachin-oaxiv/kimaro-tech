# Kimaro Tech — Dynamic React Product Store

Premium, responsive React + Vite frontend with distinct product detail views.

## Run locally
```bash
npm install
npm run dev
```

## Included
- Premium hero with selected-product imagery
- Four individual products: 4K webcam/camera, headphones, portable speaker, mechanical keyboard
- Separate color swatches per product; choosing a color updates that product's image and label
- Click any product to update the product detail section
- Category filtering and search
- Expandable specifications
- Working frontend cart drawer, item removal, subtotal and demo checkout notice
- Responsive desktop/mobile layouts

## Important
This is a frontend portfolio demo. Product photos are loaded from Unsplash and require an internet connection. Product names/specifications/prices are sample demo content. Checkout does not take payment.
